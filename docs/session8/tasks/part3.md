## Reported Issue

> Cross-site connectivity is partially working. Some workstations at the right site are reachable from the left site, but others are not. The pattern is consistent — the same destinations always succeed and the same ones always fail.

---

Investigate, identify the root cause, and apply a fix. When all left-site hosts can reach all right-site hosts without exception, the fault is resolved.
