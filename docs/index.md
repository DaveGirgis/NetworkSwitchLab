# Network Training Labs

Welcome to the CCNA style lab series. These labs are designed for adult professionals learning
enterprise networking concepts using Cisco 3725 routers with NM-16ESW modules in GNS3.

Each session builds on the previous one. Labs include full topology diagrams, addressing
tables, step-by-step tasks, verification commands, and troubleshooting guides.

## Platform Requirements

- **GNS3** 2.2 or later
- **Cisco 3725** IOS image with **NM-16ESW** module
- Recommended RAM per router: 256 MB
- All labs tested on GNS3 running locally on Windows or Linux

---

## How to Use These Labs

Each session is organized into the following sections:

- **Overview** — objectives and session summary
- **Topology** — GNS3 topology diagram and link table
- **Addressing** — IP addressing and VLAN assignments
- **Tasks** — step-by-step lab tasks with CLI snippets
- **Reference** — command reference and troubleshooting guide
